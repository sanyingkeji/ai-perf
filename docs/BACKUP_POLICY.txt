Ai Perf 本地备份目录规范（重要）
================================

1) backup/（本地专用）
- 用途：用于备份线上数据库到本地（离线留档/排查问题/回溯）。
- 规范：
  - 不允许提交到 Git（GitHub 等远程仓库）。
  - 不允许随部署脚本上传到服务器。

2) backups/（服务器侧目录）
- 用途：服务器上用于定时任务/脚本产生的备份文件存放（部署脚本会在服务器创建该目录）。
- 注意：它与本地的 backup/ 不是同一个概念，命名相近但语义不同。

3) 误提交/误跟踪的处理方式
- 如果不小心把 backup/ 加入了 Git 跟踪，请执行：
  git rm -r --cached backup/
  git commit -m "chore: stop tracking local backup folder"

4) 为什么必须这样做
- backup/ 往往包含数据库导出等敏感数据，上传到仓库或服务器都存在合规与安全风险。
